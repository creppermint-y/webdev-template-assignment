# webdev-template-assignment

Starter template for building your own personal website using HTML, CSS, and JavaScript.

## Goal

Build a simple personal website that introduces yourself. No fixed spec beyond that —
use the fundamentals (HTML for structure, CSS for style, JS for interactivity) to make
something that's yours. Add a bio, projects, hobbies, photos, links, whatever represents
you.

## Steps

1. Click **Use this template** (or **Fork**) on GitHub to create your own copy of this repo.
2. Clone your copy locally:
   ```
   git clone https://github.com/<your-username>/<your-repo>.git
   ```
3. Open `index.html`, `style.css`, and `script.js` and start editing.
4. Open `index.html` in your browser to preview changes as you go.
5. Commit and push your changes as you work:
   ```
   git add .
   git commit -m "describe what you changed"
   git push
   ```
6. (Optional) Publish it for free with GitHub Pages: repo **Settings → Pages → Deploy from branch → main**.

## Files

- `index.html` — page structure
- `style.css` — styling
- `script.js` — interactivity
